# IEEE Access requirements (verified 2026-11-26)

Sources read: ieeeaccess.ieee.org/authors/submission-guidelines/, /authors/preparing-your-article/, IEEE Author Center "Guidelines for AI-Generated Content", and the official LaTeX template `ACCESS_latex_template_20260513` (sha256 60c7efc9…5a67, downloaded from the submission-guidelines page).

| Item | Requirement | Source |
|---|---|---|
| Abstract | **150–250 words, one paragraph, no displayed equations or tables**; self-contained; include 3–4 keywords/phrases | Template `access.tex`, lines 64–71 |
| Keywords | Min 3, max 10 at submission; template: alphabetical order | Submission checklist item 12; template |
| Biographies | Required for ALL authors, placed below References; author photo with biography (1in × 1.25in) | Checklist item 6; template §"Author photos" |
| Length | No page limit; strongly recommended < 20 pages; > 20 pages may be returned | Checklist item 17 |
| Files | Both LaTeX (or Word) source and PDF required; contents must match; ≤ 40 MB | Checklist item 1 |
| AI disclosure | Use of AI-generated content (text, figures, images, code) **must be disclosed in the Acknowledgments**, identifying the AI system, the sections affected and the level of use. Editing/grammar-only use: disclosure recommended. Guidelines page also asks that sections with AI-generated text cite the AI system | Preparing-your-article; Author Center AI policy; checklist item 2 |
| Fabrication | "any article found to include fabricated content of any kind will be promptly rejected" | Preparing-your-article |
| Data/code statement | Not mandated on these pages; supplemental material (code, data) allowed. We include a Data and Code Availability section anyway (prompt requirement) | Submission guidelines |
| References | Check accuracy; no retracted references; no irrelevant references. Template uses IEEEtran.bst (IEEE numeric style) | Submission guidelines; template |
| Similarity | All submissions scanned incl. similarity to authors' own work; expanded conference versions must be < 35% similar | Submission guidelines |
| Desk-reject triggers | Not following guidelines; poor grammar ("immediately rejected"); plagiarism; out of scope; duplicate submission | Submission guidelines |
| Graphical abstract | Not required (a video, if supplied, becomes the GA) | Submission guidelines |
| APC | US$2,160 per article (plus local taxes), no page limit (FAQ). Prompt notes ~20% less with IEEE + Society membership (not verified on the APC page) | Submission guidelines FAQ |

Known discrepancies on the official page: two FAQ copies differ on >20-page rules; checklist PDF (2026/10) not machine-readable, so checklist-only items are taken from the HTML copy.
