# Task-Scoped Data Entitlements (TSE) for LLM data agents

Code, preregistration, run logs and paper sources for *"Task-Scoped Data Entitlements: Deriving and
Database-Enforcing Least-Privilege Data Access for LLM Agents"* (submitted to IEEE Access).

TSE gives an LLM data agent a separate, short-lived PostgreSQL credential for each task:

1. **Infer.** A trusted broker infers the tables, columns and rows the natural-language task needs.
2. **Compile.** It compiles that scope into an ephemeral schema of `security_barrier` views owned by the user's
   role, plus an ephemeral login.
3. **Widen.** It offers a bounded, audited widening request when the scope is insufficient.
4. **Tear down.** It drops everything when the task ends.

The agent's only credential is the ephemeral login.

## Repository layout

| Path | Contents |
|---|---|
| `tse/` | Library: scope model (`scope.py`), semantic layer, scope inference (`infer.py`), compilation and broker (`compile.py`), widening policies (`widen.py`), agent environment and harnesses (`env.py`, `agents/`), metrics |
| `spec/tse-model.md` | Formal model: entitlement, task scope, sufficiency, over-exposure ratio (OER), widening bound, design-guarantee Remark |

| `eval/results/` | Raw run logs (JSONL) for all experiments |
| `eval/NUMBERS.md` | Map from each number in the paper to its source file and computation |
| `paper/` | LaTeX sources (IEEE Access template); `paper/numbers.tex` and `paper/tables/` are generated |
| `supplement/` | Supplementary material (prompts, injection templates, bypass catalog, extra tables) |
| `review/` | Self-review gates: number consistency, references, overlap, lesson audit, independent reviews, rebuttal notes |
| `tests/` | Unit tests (enforcement tests need the experiment cluster) |
| `data/DATASETS.md` | Dataset versions, licenses, checksums and processing |

## Reproduce the paper's numbers (no database or API needed)

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
PYTHONPATH=. .venv/bin/python eval/aggregate.py   # rewrites paper/numbers.tex, paper/tables/*, paper/figs/fig_e1.pdf
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`aggregate.py` reads only committed files in `eval/results/` and `data/tasks/`. A clean clone regenerates every
macro and table byte-for-byte; the API-spend total is the only number that is not reproduced.

## Re-run the experiments

Re-running the experiments needs:

- PostgreSQL 16 (we used 16.16) on port 5433.
- The BIRD Mini-Dev PostgreSQL databases and Spider dev, as described in `data/DATASETS.md`.
- Ollama (we used 0.35.0) serving `qwen2.5-coder:7b`, `qwen3:8b` and `llama3.2:3b`.
- For the Claude arms, an Anthropic API key in `~/.anthropic_key`. The total spend for the paper was about
  US$61; a spend cap is enforced in code through `TSE_API_CAP_USD`.

Steps:

1. `tse/setup_db.py` hardens the cluster and creates owner, user and broker roles.
2. `eval/prepare.py` assigns roles and builds the task sets.
3. `eval/run_inference.py` caches scope proposals.
4. `eval/run_agents.py` runs the agent experiments. `eval/launch_phase_a.sh` shows the exact invocations used.
5. Run `eval/run_e1_e3.py`, `eval/run_e4.py` and `eval/run_e5b.py`.
6. Run `eval/aggregate.py` to regenerate the paper's numbers.
